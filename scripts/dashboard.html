        Implantações

        Novidades transformadas em skills e enviadas por commit para os seus projetos no GitHub.

        Para implantar: abra Descobertas, escolha um item e clique em Implantar nos projetos. A IA escreve uma skill; você confere a prévia e confirma. O AES só grava arquivos de skill (SKILL.md), nunca código da aplicação.

        Projetos

        Repositórios do GitHub que recebem as skills adotadas por commit direto no branch principal.

        IA e GitHub

        Qual modelo escreve as skills e como o AES acessa os seus repositórios. As chaves ficam salvas só no servidor e nunca voltam para o navegador.

        Piloto automático

        A cada 3 minutos o AES traduz e avalia as novidades, consulta Hacker News e GitHub, busca repositórios em alta e, com o piloto ligado, implanta nos seus projetos as que passarem dos limites. Você acompanha em Implantações e pode reverter.

        GitHub

        1. No GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
        2. Em Repository access, escolha os repositórios que o AES pode alterar.
        3. Em Permissions → Repository, dê Contents: Read and write (Metadata fica como leitura).
        4. Copie o token gerado e cole abaixo.
