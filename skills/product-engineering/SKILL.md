# Product Engineering

1. Read `.agent-engineering/core/product-quality.md` and `engineering-charter.md`.
2. Inspect existing product patterns and understand the user workflow before designing.
3. Define the user goal, actors/permissions, success criteria, and important failure states.
4. Identify the complete workflow: entry point, primary action, validation, success feedback, cancellation, recovery, and relevant audit trail.
5. Use the existing design system unless evidence supports changing it. Use current references to resolve specific questions, not to imitate a product wholesale.
6. Implement appropriate empty/loading/error/unauthorized/responsive states.
7. Verify the workflow and accessibility with available tools.
8. Report omissions or environmental limitations explicitly.
